Chapter 2

The architecture

Five boxes. Three of them we built and run ourselves; two are outside services we talk to. Once you can name these five and the arrows between them, you understand the system's skeleton.

The five boxes, one by one

1 · The web server (Caddy — the web container)

The browser only ever talks to this one address. Caddy does two jobs at once: it hands the browser the website files (HTML/JavaScript), and it acts as a reverse proxy — any request whose address starts with /api/ or /auth/ is quietly forwarded to the backend. Because the website and the API appear to live at the same address ("same origin"), the login cookie is sent automatically and there's no complicated cross-site setup.

Caddy is the building's front desk. Guests only ever speak to the desk; the desk either hands them a brochure (the website) or phones the right department (the backend) on their behalf.

2 · The backend (FastAPI, Python — the api container)

This is the brain of the operation in the engineering sense: it checks who you are, enforces what you're allowed to do, reads and writes the databases, runs the ingestion pipeline (Capture → Triage → Comprehend → Index), talks to the AI, and meters the cost. Everything trustworthy happens here. It's the backend/src/ folder.

3 · The databases (PostgreSQL — the db container)

One Postgres server holds many databases. The control plane (iota_control) is the shared directory + billing ledger. Then there is one brain database per customer (iota_tenant_acme, …), each holding only that customer's knowledge. (A legacy single-customer brain called iota_brain still exists for the cred-free local demo.)

This separation is the product's central safety promise: customer A's data physically lives in a different database from customer B's. Chapter 3 opens both up.

4 · LLMBase (outside service)

The EU-hosted, OpenAI-compatible AI endpoint. The backend sends it text and gets back text — to comprehend an email into entities, or to write a cited answer. It's the place the backend itself sends data to a third party, chosen to keep that processing inside the EU. (One other route exists, but only at a user's own request: if they connect an MCP client, their brain answers flow out to their assistant — Claude or ChatGPT — see Chapter 7.)

5 · The customer's mail & identity (Microsoft, or IMAP + native login)

For a Microsoft customer this is their own Microsoft 365: Entra handles login (staff sign in with their work account) and Graph is the door through which Iota reads the mailbox it's been granted — both require the customer to grant permission first.

But Microsoft isn't required. A customer on any other mail host connects their mailbox over plain IMAP instead (an app password, stored encrypted), and their staff sign in natively — email + password + an authenticator app — with no outside identity service at all. So box 5 is really “where mail and logins come from,” and for a non-Microsoft customer the mail half is the IMAP host while the login half lives entirely inside our own control plane. Chapter 5 walks both sign-in paths.

Two ways the same code runs

The exact same backend code runs in two modes, which is why you'll see two sets of Docker files in infra/:

  • local infra/local/ — a faithful copy of production on your laptop at http://localhost:8080, used to preview changes. (Every screenshot in Chapter 4 was taken here.)
  • prod infra/prod/ — the real server, with HTTPS and real customer credentials.

Two front doors into the backend

Most traffic comes through the website — a person in a browser, carrying a login cookie. But the backend exposes a second door at /mcp: an MCP server (backend/src/mcp_server.py) that lets an AI assistant — Claude or ChatGPT — use a customer's brain as a set of tools. That caller is a program, not a browser, so it proves itself with a bearer token instead of a cookie, obtained through our own OAuth flow, and is scoped to one workspace, read-only. Same data and same backend; different doorway and different proof of identity. Chapter 7 is the whole story.
