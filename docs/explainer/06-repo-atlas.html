Chapter 6

The repo atlas

Not a list to read top-to-bottom — a map you open as you go. The whole repository is four folders. The tree on the left is pure navigation: indented, collapsible, names only. Click anything and its explanation opens in the pane on the right.

The four signposts

Everything in the repo hangs off one of these. This is the mental model to keep while you explore the tree.

backend/ — the engine

Python (FastAPI), the database schema, and all the real logic: the four-phase ingestion pipeline, the graph, search, auth, billing.

frontend/ — the face

The Next.js/React website you click around in — pages, reusable components, and the thin client that calls the backend.

infra/ — the plumbing

Docker recipes and web-server config to run the whole stack identically on a laptop and in production.

docs/ — the notes

Internal docs — the data-processing agreement, the cost model, and this explainer. Never shipped to customers.

How to use it: the left is navigation, the right is explanation. Click a folder name to open it (+ → −) and see what it's for; click a file to read its one-line job in the pane. The heart of the system is backend/src/ingestion/ — one process, four phases (capture → triage → comprehend → index), exactly the chapters you've just read.
